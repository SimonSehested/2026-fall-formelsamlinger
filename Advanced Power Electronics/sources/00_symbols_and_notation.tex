\section{Symboloversigt}

\subsection{Ctrl+F keywords: symbol, notation, units, meaning, variabel, enhed, Symboloversigt, glossary, duty ratio, ripple, resonant}

Use this index when a formula contains an unfamiliar quantity. Topic chapters assume the meanings below.

Overloaded symbols: \(D\) is duty ratio except in component tables where \(D\) is the diode; \(N\) is turns ratio except when used as winding index \(N_1,N_2,N_3\); \(\Phi\) is the QRC normalised load (not magnetic flux).
